# 资料库结构与维护规则

资料库为人类与AI协作开发提供可直接使用的背景知识。每条事实集中维护在对应主题，通过链接供其他文档引用。

| 目录 | 内容 |
|---|---|
| 000-基础认识 | 项目目标、术语和阅读入口 |
| 100-现今背景资料 | 当前设备用法、程序需求、网页需求与协同方式 |
| 200-历史版本 | 历史设计及归档说明 |
| 300-历史改进 | 实施记录、改动和测试结果 |
| 600-代办事项 | 待完成工作与确认任务 |
| 输出 | 工具、派生文件和备份 |

硬件当前版本为10-01（浇水6代-v2），从[[硬件情况概述]]阅读。正文以固件需要的引脚、设备操作、供电行为和运行参数为主；工程文件、元件网络和结构资料通过[[123-硬件查证索引]]按需查询。

参数未知时，在[[122-运行与待定参数]]记录需要确认的值及其影响。确认后填入设备说明，并更新对应待办状态。浇水算法和运行模式由程序资料维护。
