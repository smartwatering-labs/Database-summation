## 项目定位

本项目是基于 ESP32-C3 的智能全自动浇水系统，用于在**长期无人值守条件下**采集环境与土壤状态，进行对应数据处理，并按算法判断何时、如何浇水。

系统同时承担两个目标：
- 实地运行：在楼顶、户外或类似场景中定时唤醒、采样、判断、浇水、休眠
- 展示验证：在室内非实地场合，通过网页仪表盘与配置平台展示传感器数据、浇水需求、运行模式和配置下发能力

## 当前硬件版本

当前使用浇水6代-v2（10-01版本）：上板采集传感器并输出控制信号，下板连接电源并驱动执行器。开发所需的设备用法和运行条件从[[硬件情况概述]]开始阅读。

## 系统组成
项目要求把网页前后端定位为用户进入系统的主要入口：网页首页负责展示产品与快速跳转，子页面分别承担产品介绍、个性化库编译、硬件情况查看。网页需要通过蓝牙与 ESP32-C3 建立握手连接，读取设备数据，并把后端推导出的个性化配置发回单片机。

系统本身由3部分组成：

| **主体** | 分支                                              | 效果                                                                                                       |
| ------ | ----------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| 主板硬件   | - 主板与运算器<br>- 传感器<br>- 运动器<br>- 通讯器<br>- 外壳     | - 所有电器供电，信号传输，解析，处理<br>- 检测周围环境信息并将生数据传回单片机处理<br>- 等待单片机指令进行特定操作<br>- 外部信号接收与内部信号传达<br>- 产品包装与保护         |
| 芯片程序   | - 传感器数据接收与处理<br>- 条件判断与执行<br>- 蓝牙或本地网络握手与收发        | - 对于传输进生数据进行对应处理与解析<br>- 对于全局情况的判定以及对于的指令派发<br>- 对于外部信号的识别，对齐，与理解                                        |
| 网页前后端  | - 用户入口与页面导航<br>- 蓝牙握手与数据同步<br>- API调用<br>- 个性化配置推导<br>- 外部资料匹配 | - 通过第三方服务，了解用户当地环境<br>- 让用户填写植物、地点、栽培方式、光照、水源和无人值守情况<br>- 根据已知环境信息，处理部分程序的数据细节<br>- 将处理过的数据传入单片机，对于其数据处理进行客制 |
### 基础知识通览：
1. 浇水器要有三种运行模式：`DISPLAY`、`PREPARE`、`LONGRUN`。
	 DISPLAY：展示使用场景，只采用温湿度传感器的传感器的数值进行测算，活动降低，敏感度增高，平时不使用，需要管理员通过特殊信号打开
	 PREPARE：每个新芯片的初始状态，在开机后先等待网页里传来的自定义化数据包

- 传感器：DHT 温湿度、土壤湿度 ADC、雨量 ADC。
- 执行器：下板AO3400A低边MOS驱动水泵，舵机擦拭雨量传感器。
- 浇水方式：脉冲式浇水，默认 9 次，每次开泵 3 秒，间隔 25 秒。
- 低功耗：`LONGRUN` 模式使用 ESP32 deep sleep，默认 2 小时唤醒一次。
- 本地持久化：NVS 保存配置，SPIFFS 保存日志。
- 网页配置：本地设备提供配置上传/下载、重启、恢复出厂等接口。
- 网页首页：展示硬件模型或临时图片，并提供产品介绍、个性化库编译、硬件情况查看三个入口。
- 数据同步：硬件每 2 小时唤醒采样后，网页在蓝牙连接可用时同步最新数据，并支持查看一周以内的历史数据。
