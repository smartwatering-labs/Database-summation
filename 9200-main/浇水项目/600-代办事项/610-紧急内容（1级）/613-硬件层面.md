# 硬件层面

开发所需参数集中维护于[[122-运行与待定参数]]。

- [ ] 确认开发板、OLED及传感器型号，补齐驱动参数。
- [ ] 测量传感器稳定时间、三路ADC实际输入及土壤/雨量干湿数据。
- [ ] 确认舵机脉冲范围、机械行程、移动时间和停止脉冲后的行为。
- [ ] 测量水泵流量、启动电流及各负载运行时的供电稳定性。
- [ ] 确认外接电源模块接线、B-/GND关系、电池配组和充电保护。
- [ ] 验证上电、复位、休眠时关泵和传感器断电行为，检查信号回灌。
- [ ] 确认USB与外部5V并供条件，测量整机睡眠电流。
- [ ] 完成布线/装配检查及完整装配后的BLE测试。

确认值填回设备说明；测量条件和结果按日期记录到300-历史改进。
