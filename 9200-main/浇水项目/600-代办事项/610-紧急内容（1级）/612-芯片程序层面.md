# 芯片程序层面

依据[[121-设备与引脚]]和[[122-运行与待定参数]]完成以下开发事项。

- [ ] 确认主线固件及源码位置，区分主固件与配置接收固件。
- [ ] 核对实际开发板，建立统一GPIO和设备驱动配置。
- [ ] 实现水泵高开低关，启动、异常与休眠前关泵。
- [ ] 实现传感器统一供电、稳定等待、采样及断电顺序。
- [ ] 配置ADC并接入干湿标定结果、有效范围和雨量阈值。
- [ ] 按舵机参数和机构行程实现擦拭动作及收尾状态。
- [ ] 验证复位、睡眠和看门狗重启时的执行器状态。
- [ ] 使用实测流量校准脉冲浇水量。
- [ ] 统一配置字段，处理配置版本迁移和旧数据兼容。
