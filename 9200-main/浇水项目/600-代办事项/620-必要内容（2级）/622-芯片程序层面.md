# 芯片程序层面

## 中期优化

- [ ] 将传感器标定值保存到 NVS，避免每次改代码。
- [ ] 将季节模式从固定枚举扩展为可配置策略。
- [ ] 明确 `PREPARE` 模式基准校准结果如何影响土壤、温度和湿度。
- [ ] 增加日志字段版本号，避免不同固件日志格式混淆。
- [ ] 把主固件本地 API 路由整理成表，减少后续维护成本。
- [ ] 对配置上传加入更明确的错误信息。
- [ ] 检查 SPIFFS 日志轮转是否会丢失表头或关键记录。
- [ ] 增加蓝牙握手、实时数据读取、历史数据读取、配置写入的固件接口设计。
- [ ] 保留至少一周历史采样记录；按 2 小时唤醒估算不少于 84 条记录。
- [ ] 为蓝牙分包传输设计消息编号、校验、失败重试和超时处理。
- [ ] deep sleep 唤醒后明确蓝牙广播窗口和重新握手机制。

## 可维护性

- [ ] 把引脚、算法参数、协议字段分区注释。
- [ ] 将PUMP水泵MOS驱动、SENSOR-POW传感器供电和舵机操作集中封装。
