# 通信方式

## 蓝牙

网页要求用户设备与 ESP32-C3 通过蓝牙连接。蓝牙链路用于：

- 识别目标设备并建立连接。
- 执行握手，确认设备 ID、固件版本、协议版本和 nonce。
- 同步实时采样数据到硬件情况查看页面。
- 读取一周以内历史采样数据。
- 下发后端生成的个性化配置包。
- 触发模式切换、配置导入导出、重启、恢复出厂等设备操作。

蓝牙连接受 deep sleep 影响，设备休眠或重启后需要重新连接和握手。

## Flask HTTP API

Flask 平台提供临时配置生成、环境资料查询和系统监控 API，运行在电脑或服务器上。

配置生成接口：

```http
POST /api/configurations/generate
```

用于前端提交当前页面表单，并取得后端生成的临时配置包。ESP32 不主动访问后端，也不通过后端同步设备数据。

## ESP32 通信边界

第一阶段设备侧交互统一通过 BLE 完成。

## 数据格式

主要使用 JSON：

- 蓝牙握手、实时采样、历史采样、配置下发 JSON。
- 设备配置 JSON。
- 设备信息 JSON。
- Flask 临时配置生成、环境资料查询和系统监控 API JSON。

日志使用 CSV 或文本形式保存在 SPIFFS。
