# 浇水算法

> 本文保留已有算法及参数作为开发参考。传感器读取和分压换算见[[121-设备与引脚]]；干湿端点、有效范围、雨量阈值和流量使用当前硬件的标定结果。

## 输入数据

| 输入 | 来源 | 处理 |
|---|---|---|
| 土壤湿度 ADC | `SOIL_PIN` | 5 次采样取中位数，必要时结合准备期基准动态调整湿/干边界。 |
| 雨量 ADC | `RAIN_PIN` | 5 次采样取中位数，小于阈值判定为有雨。 |
| 空气温度 | DHT | 用于计算温度胁迫。 |
| 空气湿度 | DHT | 用于计算空气干燥度。 |
| 配置参数 | NVS / 上传配置 | 控制权重、阈值、脉冲次数和脉冲时长。 |

## 需求值计算

原资料记录的主固件中的需求值变量为 `curD`，计算结构为：

```cpp
curD =
  soilDryness * g_cfg.soilWeight +
  tempStress  * g_cfg.tempWeight +
  airDryness  * g_cfg.airWeight +
  5.0f;
```

计算后会裁剪到 `0-100`。

默认权重：

| 参数           |  默认值 |
| ------------ | ---: |
| `soilWeight` | 0.60 |
| `tempWeight` | 0.25 |
| `airWeight`  | 0.10 |
| 基础偏移         |  5.0 |
| `threshold`  | 50.0 |

## 土壤干燥度

代码中先确定湿端 `wetBound` 和干端 `dryBound`，再通过线性归一化得到 `soilDryness`。

旧固件参数（迁移参考，非新版标定值）：

- `SOIL_WET_ADC_REAL = 15`
- `SOIL_DRY_ADC_REAL = 5`
- `SOIL_VALID_MIN = 3`
- `SOIL_VALID_MAX = 300`

> [!warning] 待硬件确认
> 这些值和旧背景中“1000=湿、4095=干”的描述冲突，也和常规 ESP32 ADC 量程直觉不一致。需要用当前传感器和当前接线实测后确认。

## 温度胁迫

- 默认温度起算阈值为 28 摄氏度。
- 如果准备期基准温度在 15-40 摄氏度之间，则使用 `max(rtc_baselineTemp, 28.0f)` 作为温度阈值。
- 超过阈值的温度差映射到 `0-100`，满量程按 12 摄氏度温差计算。

## 空气干燥度

空气干燥度为：

```cpp
airDryness = clamp(100.0f - curH, 0.0f, 100.0f);
```

DHT 数据无效时，温度胁迫和空气干燥度不会按当前值更新。

## 雨量硬否决

当 `curR < RAIN_WET_THRESHOLD_ADC` 时判定为有雨。

旧阈值（新版待标定）：

```cpp
RAIN_WET_THRESHOLD_ADC = 1000
```

检测到有雨或土壤数据无效时：

```cpp
curD = 0;
```

## 自动浇水触发

`LONGRUN` 模式中，自动浇水需要同时满足：

- 当前未下雨。
- `curD >= g_cfg.threshold`。
- 当前不在浇水周期。
- 距离上次浇水的唤醒次数达到季节要求。

季节唤醒次数：

| `rtc_seasonMode` | 含义 | 需要唤醒次数 | 约等价时间 |
|---:|---|---:|---|
| 0 | 冬季 | 72 | 6 天 |
| 1 | 春秋 | 48 | 4 天 |
| 2 | 夏季 | 24 | 2 天 |

按默认 2 小时唤醒一次估算。

## 脉冲浇水状态机

默认参数：

- `pulseCount = 9`
- `pulseOnMs = 3000`
- `pulseOffMs = 25000`

执行逻辑：

1. 进入浇水周期后，若水泵关闭且脉冲步数未达上限，则开泵。
2. 开泵到达 `pulseOnMs` 后关泵，进入等待。
3. 关泵等待 `pulseOffMs` 后进入下一次脉冲。
4. 达到 `pulseCount` 后结束周期，重置 `rtc_pulseStep` 和 `rtc_wakesSinceLastWater`。

## 网页平台参数推导

网页平台的 `derive_parameters()` 根据植物、地点、花盆、光照、水源等推导：

- `soil_weight`
- `temp_weight`
- `air_weight`
- `demand_threshold`
- `pulse_count`
- `pulse_on_ms`
- `pulse_off_ms`
- 单轮浇水量估算
- 浇水间隔估算
- 续航天数估算

其中水泵流量估算使用：

```python
FLOW_RATE_L_PER_S = 0.022
```

这个估算值需要和实际水泵流量实测校准。
