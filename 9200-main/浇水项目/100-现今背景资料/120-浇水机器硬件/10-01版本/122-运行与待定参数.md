# 运行与待定参数

## 启动与采样顺序

1. 初始化水泵为关闭、传感器电源为关闭，配置ADC及通信接口。
2. 开启传感器总电源，按已确定的稳定时间等待。
3. 读取温湿度、土壤、雨量及太阳能电压，检查数据有效性。
4. 完成传感器读取后关闭其电源；若随后需要复测，再执行上电和等待。
5. 将数据交给[[113-浇水算法]]，按结果驱动水泵、舵机，处理显示和通信。
6. 休眠前关泵，完成舵机动作与脉冲收尾，确认传感器电源关闭。

启动及休眠的引脚设置见[[121-设备与引脚]]。采样间隔和浇水周期由程序运行模式决定。

## 供电对程序的影响

- 系统目标供电为5V，来自太阳能/电池及外接电源模块。
- 水泵、舵机和主控共用系统供电。首次调试应分别运行各负载，再验证同时动作时的稳定性。
- 深度睡眠期间开发板、OLED、舵机和外接电源模块仍可能耗电；续航按整机实测电流估算。
- 调试时使用外部仪表测量VIN跌落与运行电流。通过USB烧录前，核对开发板的USB与外部5V并供条件。

## 编程所需的待定参数

| 参数 | 需要确认的内容 | 影响的代码 |
|---|---|---|
| 开发板 | 实际型号与GPIO对应、USB并供条件 | 引脚定义和烧录调试 |
| OLED | 控制器、分辨率、I²C地址 | 显示驱动初始化 |
| 传感器 | 实际型号、上电稳定时间、读取间隔 | 驱动选择与采样时序 |
| ADC | 分辨率、衰减、校准方式及最大实际输入 | ADC初始化和电压换算 |
| 土壤 | 干湿端点、有效范围及读数变化方向 | 干燥度计算和异常判断 |
| 雨量 | 干湿读数、变化方向、阈值及擦拭后稳定时间 | 有雨判断与复测 |
| 舵机 | PWM周期、脉宽范围、角度边界、移动时间与收尾行为 | 擦拭动作和休眠准备 |
| 水泵 | 流量、启动电流、适用开泵时长 | 浇水量估算和动作安排 |
| 电源 | 模块型号、负载能力及各运行状态实测电流 | 同时动作策略和续航估算 |

参数确认后填回对应设备说明。土壤/雨量阈值与舵机动作范围完成标定后，再启用自动浇水和擦拭。实施事项分别跟踪于[[612-芯片程序层面]]、[[613-硬件层面]]。
