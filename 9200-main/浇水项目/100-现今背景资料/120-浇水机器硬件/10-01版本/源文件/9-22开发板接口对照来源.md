# 上板接口与GPIO分配

## ESP32-C3引脚分配

| ESP32-C3引脚 | 网络名称 | 方向 | 用途 |
| --- | --- | --- | --- |
| GPIO0 | SENSOR-POW | 输出 | 外部传感器电源总开关，高电平开启 |
| GPIO1 | SOLAR-PRS | ADC输入 | 太阳能板电压检测 |
| GPIO2 | SERVO | 输出 | 9G舵机PWM控制信号 |
| GPIO3 | RAIN | ADC输入 | 雨量传感器模拟信号 |
| GPIO4 | SOIL | ADC输入 | 土壤湿度传感器模拟信号 |
| GPIO5 | OLED-SDA | 内部I²C | 板载OLED数据线 |
| GPIO6 | OLED-SCL | 内部I²C | 板载OLED时钟线 |
| GPIO7 | PUMP | 输出 | 下板水泵驱动或继电器的控制信号 |
| GPIO8 | 未使用 | — | 板载指示灯相关引脚，当前不分配 |
| GPIO9 | 未使用 | — | BOOT相关引脚，当前不分配 |
| GPIO10 | DHT | 双向数字 | DHT11单总线数据 |
| GPIO20 | RX | 串口输入 | 为烧录、批量编译和调试保留 |
| GPIO21 | TX | 串口输出 | 为烧录、批量编译和调试保留 |

GPIO20和GPIO21不得再分配给传感器或执行器。

## ESP32开发板两侧排母

### 左侧，由上至下

| 排母位置 | 开发板引脚 | 上板用途 |
| --- | --- | --- |
| L8 | 5V | 上板VIN输入 |
| L7 | GND | 公共地 |
| L6 | 3.3V | 不作为外部电源输入 |
| L5 | GPIO20/RX | RX测试与烧录接口 |
| L4 | GPIO21/TX | TX测试与烧录接口 |
| L3 | GPIO2 | SERVO |
| L2 | GPIO1 | SOLAR-PRS |
| L1 | GPIO0 | SENSOR-POW |

### 右侧，由上至下

| 排母位置 | 开发板引脚 | 上板用途 |
| --- | --- | --- |
| R8 | GPIO10 | DHT |
| R7 | GPIO9 | 未使用 |
| R6 | GPIO8 | 未使用 |
| R5 | GPIO7 | PUMP |
| R4 | GPIO6 | OLED-SCL |
| R3 | GPIO5 | OLED-SDA |
| R2 | GPIO4 | SOIL |
| R1 | GPIO3 | RAIN |

## 上下板接口

上下板之间提供以下连接：

- 多个VIN/5V引脚，用于向上板供电并降低单针接触阻抗。
- 多个GND引脚，所有电路共地。
- SOLAR-IN：下板送来的太阳能板电压检测信号源。
- SERVO：上板送往下板的舵机控制信号。
- PUMP：上板送往下板的水泵控制信号。

水泵与舵机的功率电源不经过ESP32排针，也不经过SERVO或PUMP信号线。

## 传感器接口

- DHT11：VCC、SIG、GND三针。
- 土壤湿度：VCC、SIG、GND三针。
- 雨量：包含CTR-PWR、GND和信号端；未使用脚在丝印中应明确标为NC。

接口丝印中的VCC在传感器区域代表受控的CTR-PWR，而不是永久供电的VIN。
