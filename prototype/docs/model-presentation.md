## 模型、材质与替换

2026-10-09 更新：展示使用用户提供的 3D watering box-9-30ver.obj 转换得到的 watering-box-9-30ver.glb。648 个原始实体分属独立顶盖、上层主板、下层主板、底壳，元器件及背面引脚随所属主板一起移动。同层同物理材质网格合并为绘制网格（10-12 独立丝印后共 25 个），使用索引几何，GLB 约 11.9 MB。原始附件和部件尺寸未修改。

tools/build_watering_model.py 使用 Python 标准库从该版本 OBJ 重新生成 GLB；按原始实体顺序保留两层装配关系，不通过切割高度把引脚或电池座切开。sourceSolids 元数据记录所有原始实体的归属。该脚本专用于此 CAD 导出，新版源模型需要重新核对实体分组。

```powershell
python tools/build_watering_model.py "C:\Users\bYYYyyL\Desktop\3D watering box-9-30ver.obj"
```

static/assets/models/model.json 为模型配置入口：

- url、materials：本地模型和材质路径；format 为 obj 或 glb，GLB 不需要 materials。
- upAxis：当前源模型 Z 向上，使用 z；标准 Y-up 模型使用 y。
- parts：独立节点名称、kind 与各页面 states；offset 为原始坐标系中的平移偏移量，opacity 控制移除的外壳。不要把世界坐标误填为偏移量。
- poses：四页的 rotation 欧拉角（弧度）、可选 rotationOrder、open 状态，以及 frame.desktop / frame.mobile。默认顺序 YXZ；首页、产品页和硬件页显式使用 XYZ，使偏转后侧壁、器件与爆炸方向保持竖直。center 是画布中的中心比例，fill 是最大宽高占比。首页约 16° 俯角，取景避开标题，右侧辅助按钮不再整行限制模型高度；1200px 及以上产品页利用列表右侧的完整高度呈现四层爆炸图，高度上限占比 91%；768–1199px 的产品模型区域至少 1040px 并居中，手机至少 680px、宽度占比上限 86%，随页面滚动，以保证每层可辨。产品页移除底部标语与页脚留白，桌面列表和操作入口利用完整高度。

源文件顶盖为分离位置，实际是套在底壳外侧的结构。首页将其沿源 Z 轴偏移 -4.857305，使顶盖内顶面落至底壳上沿上方 0.02 个源单位，盖子压下并包裹底壳侧壁。旧的外沿对接装配会导致盖子悬高、整机过厚，已移除。产品页顶盖、上层主板、下层主板和底壳分别偏移，四层在画面中均保留可见间距。此处是展示装配，不能用于制造公差判断。

2026-10-12：外壳为微暖白 ABS 塑料 PBR 材质，金属度为零；本地生成的细微纹理只影响粗糙度，不再使用外壳凹凸贴图。基础粗糙度 0.36、IOR 1.48、镜面强度 1、清漆 0.015；实际粗糙度还乘以非颜色纹理。上下壳使用同一种塑料，避免不同灰度造成金属拼接的观感。底壳 ON/OFF 原始字形的 156 个三角面独立使用黑色丝印材质，仍随底壳移动和渐隐，原始轮廓及凹刻几何保持不变；材质拆分后为 25 个网格，648 个实体归属保持不变。

内部按物理用途区分深蓝阻焊层、FR4 板边、白色丝印、哑光环氧芯片封装、缎面接插件/电池座塑料、镀金触点、银色焊锡/镍层、陶瓷及透镜；源文件中同为白色的丝印与金属不共用材质。阻焊层采用低强度镜面反射和薄涂层，以保留颜色与元器件对比；芯片与注塑接插件分别使用不同的粗糙度及细颗粒纹理。外壳与内部组件均投射、接收 VSM 柔化阴影；采用 FrontSide 和 normalBias 减轻 CAD 背面投影条纹。运行时无在线贴图或环境资源请求；旧 Metal012 素材保留来源记录，但不再用于当前模型。

替换正式模型：

1. 将模型放入 static/assets/models/。推荐带独立命名节点的未压缩 GLB，外壳、盖板和可展开部件分别命名。
2. 修改 model.json 的路径、格式、向上轴、部件名称与偏移。核对新模型节点，不能直接复用旧名称。
3. 校准四页角度、取景和开合距离。模型按源 XY 占地统一尺度，每页按仍可见的部件计算中心与取景，移除的外壳不会把主板中心拖低。直接访问页面与从其他页进入采用相同结果。
4. 如正式模型自带成品纹理、透明材质，调整 model-stage.js 的材质替换段以保留它们。当前未配置 Draco/KTX2 解码器。
5. 检查全部有向页面切换、快速连续切换、展开边界和手机取景。无需修改业务服务、Python API 或构建应用。

## 动画与资源生命周期

model-stage.js 在可重绘的 main 外、main-shell 内持有单个 WebGL 场景与 Canvas。Canvas 在文档中绝对定位，随文档滚动，不使用滞后的屏幕坐标插值；滚动不会额外改变模型姿态。

仅在功能页面板收起后，Canvas 接收鼠标/触摸拖动旋转；方向键也可旋转，Home 键或双击归位。滚轮和双指缩放限制在 0.7–1.75 倍。展开面板时从实际方向、缩放平滑返回该页默认姿态；切页同样关闭自由旋转并直接转至最新目标。使用 Pointer Capture 与仅查看模式下的 touch-action:none，避免页面滑动与拖动冲突。手机面板按钮直接处理触摸点按并去重兼容 click；模型尚未加载时打开预览，操作意图也会在加载完成后保留。

切页时将旧内容复制为不可交互的短暂快照，120ms 淡出与模型运动同时开始；新页面内容先隐藏。模型从当前实际姿态做 420ms 四元数球面插值，位置、比例、旋转中心和四层开合使用同一段平滑进度；页面展示区高度改变时保持模型的屏幕位置和大小连续。模型到位后以 150ms 渐显新内容。导航版本号取消过期切换，不会逐页排队；连点导航直接转至最新目标。取景计算仅在内容、路由或画布尺寸变化时更新，不再每帧读取页面布局。WebGL 缓冲高度按视口保持稳定，逻辑相机仍按展示区尺寸取景，减少切页时重新分配缓冲的停顿。转场开始时地面阴影用 120ms 淡出，模型到位后用 240ms 淡入；快速切页从当前透明度继续，阴影帧循环独立延续，不延迟模型到位后的文字渐显。减少动画时直接显示最终状态。材质预编译且外壳淡出不切换着色器类型；实机帧率仍取决于 GPU 和浏览器。

surface-motion.js 使用同一个 requestAnimationFrame 进度驱动内容透明度、面板位移及模型模糊程度；模型模糊为 8px × 内容显示进度 × 面板展开进度。面板取消 backdrop-filter，避免外层 opacity/filter 动画改变 backdrop 合成边界引发先后生效。面板收放 440ms，模型默认归位 420ms，可中途反向，无动画队列。初始渲染、减少动态效果及零时长情况直接赋终态，避免除零产生无效动画值。

外壳的透明度沿模型姿态的平滑进度连续变化，透明材质与深度写入状态在动画前后保持不变。取消接近完全不透明时才启用深度写入的阈值，避免背面叠加与遮挡突然改变产生实体跳现。shell-fade.test.cjs 记录实际 WebGL 绘制的 opacity 与深度状态，并截图检查硬件页返回首页的透明、半透明和实体阶段。

接近目标后停止帧循环；隐藏标签页暂停，卸载时释放 GPU 资源。减少动态效果模式直接到终态。模型或 WebGL 加载失败时展示原硬件参考图，保留业务入口。

动效参考 [React Bits](https://reactbits.dev/get-started/index) 的 VariableProximity、ClickSpark 与 AnimatedContent，适配为原生 JS/Web Animations/CSS，不引入 React 构建链。按钮点击有短暂扩散线条与按压回弹；配置结果、写入反馈渐显；详情弹窗与其背景同步进入/退出。参考许可在 docs/references/react-bits-license.md。

Logo 始终使用主题的深色文字色。使用本地 Roboto Flex 可变 WOFF2（wght 400→900、opsz 9→40），按鼠标 100px 范围内的线性距离衰减，并以 130ms 时间常数持续收敛；鼠标停下后仍继续平滑过渡。固定字母排版宽度，取消模拟描边，避免加粗时字母挤动。字体来自 Google Fonts，SIL OFL 保存在 static/assets/fonts/OFL.txt，原始来源 CSS 仅供追溯，网页不在线请求字体。减少动态效果时停留在基础字重。

Three.js 固定 r180；本地 loader 裸 three 导入改成相对路径以兼容原有 CSP。MIT 许可保留在 static/vendor/three/LICENSE。

模型预览采用固定轴转台：左右拖动旋转，上下拖动改变俯仰，按该页 rotationOrder 从保存的 yaw/pitch 重建姿态，roll 始终为零。读取默认姿态与手动旋转使用相同顺序，避免首次拖动跳变。鼠标向右拖动时面向视线的模型表面向右移动，向下拖动时向下移动；正俯视也能立即向下拖动，不受旧的顶部角度限制。俯仰范围为 -π + 0.02 至 π - 0.02，横向可连续转动。拖动起点保存两轴角度，主方向之外的 8px 小幅抖动忽略，斜拖同时调整两轴。指针直接更新姿态，松手不附加惯性滑转；滚轮缩放使用 45ms 收敛，双指直接跟随。
