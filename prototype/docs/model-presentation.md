# 工业风视觉与 3D 展示

2026-09-28。保留四页导航、业务表单、设备/BLE 服务、数据接口和独立管理端；依据《排版基础.pptx》调整为大幅模型主体、纯白背景、蓝色重点色与悬浮面板。新增独立极简配色层、移动端导航修复、模型自由旋转及固定时长转场。运行方式仍为本机 Python + Flask/Waitress，无前端构建步骤。PPT 占位文字未作为网站文案或额外指令采用。

## 页面与交互

| 页面 | 目标姿态与内容 |
| --- | --- |
| 首页 | 正面轻微偏转、合拢；关键标题与连接入口常显，详细内容收入悬浮按钮 |
| 产品介绍 | 斜向俯视、合拢；工作原理、运行流程、运行模式、首次使用通过按钮展开 |
| 个性化库编译 | 俯视展开，芯片位置留空；全部表单和生成结果位于常驻玻璃面板 |
| 硬件情况查看 | 平视合拢；连接、采样、历史、设备操作位于常驻玻璃面板 |

功能页面板默认完整展开，占满主内容区并保留四周留白。桌面配置页将表单与配置预览并排，硬件页将当前采样/趋势与设备操作并排；手机使用单栏。工具条“查看 3D 模型”将面板平滑收到右侧，模型恢复清晰；“返回配置面板/硬件面板”恢复原输入与滚动位置。收起时面板 inert，键盘不会进入隐藏控件。长内容在面板内滚动，业务重绘后保持滚动位置。侧栏默认展开，可平滑收起/展开，移动端沿用菜单入口。

presentation.js 重组现有页面节点，保留业务控件、ID 和操作事件。说明文字完整进入独立原生 dialog，支持 Escape、关闭按钮、背景点击和关闭后焦点返回，打开时锁住背景滚动；原业务确认窗口保持独立。

## 模型、材质与替换

展示使用用户提供的壳子雨板二件套3.obj 与同名 MTL 的本地副本，保留三个独立部件。原始附件未修改。旧演示 PPT 内嵌 GLB 合并了部件，实际展示选择可拆分的 OBJ。

static/assets/models/model.json 为模型配置入口：

- url、materials：本地模型和材质路径；format 为 obj 或 glb，GLB 不需要 materials。
- upAxis：当前源模型 Z 向上，使用 z；标准 Y-up 模型使用 y。
- parts：独立节点名称及原始坐标系中的 closed / open **平移偏移量**，在装配尺寸归一化前应用。不要把世界坐标误填为偏移量。
- poses：四页的 rotation 欧拉角（弧度，XYZ）、position 归一化场景坐标（X/Y）、scale 显示比例及 open 展开量（0=合拢，1=展开）。

源文件盖板远离主体。当前盖板平移约 [-0.25,-11.05,0] 对齐主体，展开时上移 4.8 个源单位；另一部件沿源 Y 轴外移 2.2。此处为临时模型的视觉装配，不能用于制造公差判断。内部没有虚构芯片。

表面使用本地 [ambientCG Metal012](https://ambientcg.com/view?id=Metal012) 工业金属 PBR 贴图，包含颜色、粗糙度、OpenGL 法线和金属度。按源网格法线补充平面 UV，调整纹理颗粒，加入各向异性反射及 Three.js RoomEnvironment 棚拍光照。素材采用 [CC0 许可](https://docs.ambientcg.com/license/)，来源记录在 static/assets/materials/LICENSE.md。运行时无在线贴图或环境光资源请求。

替换正式模型：

1. 将模型放入 static/assets/models/。推荐带独立命名节点的未压缩 GLB，外壳、盖板和可展开部件分别命名。
2. 修改 model.json 的路径、格式、向上轴、部件名称与偏移。核对新模型节点，不能直接复用旧名称。
3. 校准四页角度、位置、比例与开合距离。模型按合拢包围盒自动居中并统一尺度。
4. 如正式模型自带成品纹理、透明材质，调整 model-stage.js 的材质替换段以保留它们。当前未配置 Draco/KTX2 解码器。
5. 检查全部有向页面切换、快速连续切换、展开边界和手机取景。无需修改业务服务、Python API 或构建应用。

## 动画与资源生命周期

model-stage.js 在可重绘的 main 外、main-shell 内持有单个 WebGL 场景与 Canvas。Canvas 在文档中绝对定位，屏幕位置由浏览器随文档滚动，不使用滞后的屏幕坐标插值。滚动角度读取完整可滚动范围，顶部与底部保持同步。

仅在功能页面板收起后，Canvas 接收鼠标/触摸拖动旋转；方向键也可旋转，Home 键归位。展开面板时从实际观看方向平滑回到该页姿态，随后禁用模型交互；切页同样关闭自由旋转并直接转至最新目标。使用 Pointer Capture 与仅查看模式下的 touch-action:none，避免页面滑动与拖动冲突。手机面板按钮直接处理触摸点按并去重兼容 click，避免拖动后首个点击被浏览器吞掉。已删除蓝色的芯片占位提示，模型内部仍留空。

点击导航时立即开始模型运动，同时在 90ms 内隐藏文字与按钮。模型从当前实际姿态做 440ms 固定时长的四元数球面插值，位置、比例和开合使用相同进度，完成时精确到终态。模型到位后以 180ms 渐显文字，常规切页总时长约 620ms；本机浏览器测试测得 628–630ms。导航版本号取消过期切换，不会逐页排队或保留指数收敛长拖尾。实机帧率仍取决于 GPU 和浏览器。

surface-motion.js 使用同一个 requestAnimationFrame 进度驱动内容透明度、面板位移及模型模糊程度；模型模糊为 8px × 内容显示进度 × 面板展开进度。面板取消 backdrop-filter，避免外层 opacity/filter 动画改变 backdrop 合成边界引发先后生效。收放与模型归位均为 440ms，可中途反向，无动画队列。初始渲染、减少动态效果及零时长情况直接赋终态，避免除零产生无效动画值。

接近目标后停止帧循环；隐藏标签页暂停，卸载时释放 GPU 资源。减少动态效果模式直接到终态。模型或 WebGL 加载失败时展示原硬件参考图，保留业务入口。

动效参考 [React Bits](https://reactbits.dev/get-started/index) 的 VariableProximity、ClickSpark 与 AnimatedContent，适配为原生 JS/Web Animations/CSS，不引入 React 构建链。按钮点击有短暂扩散线条与按压回弹；配置结果、写入反馈渐显；详情弹窗与其背景同步进入/退出。参考许可在 docs/references/react-bits-license.md。

Logo 始终使用主题的深色文字色。使用本地 Roboto Flex 可变 WOFF2（wght 400→900、opsz 9→40），按鼠标 100px 范围内的线性距离衰减，并以 130ms 时间常数持续收敛；鼠标停下后仍继续平滑过渡。固定字母排版宽度，取消模拟描边，避免加粗时字母挤动。字体来自 Google Fonts，SIL OFL 保存在 static/assets/fonts/OFL.txt，原始来源 CSS 仅供追溯，网页不在线请求字体。减少动态效果时停留在基础字重。

Three.js 固定 r180；本地 loader 裸 three 导入改成相对路径以兼容原有 CSP。MIT 许可保留在 static/vendor/three/LICENSE。

## 磨砂白配色与移动端

统一磨砂白：背景 #FFFFFF、正文 #1D1D1F、辅助文字 #86868B、交互蓝 #0066CC。工作面板使用带少许冷灰的高不透明度底色、柔和双层阴影和内侧高光；弹窗保留强磨砂背景。工作面板的磨砂沿用模型共用模糊进度，不增加第二层随面板移动的背景模糊。内部卡片的 1px 外框与行分隔线使用同一灰度，按钮以轻微投影区分可操作层。

旧版蓝灰配色和侧栏配色选择器已移除。static/css/theme-minimal.css 是唯一的外观层，不再按主题属性切换。theme.js 仅清理旧书签中的 theme 参数，保留路由、其他参数和历史状态，不刷新页面或写入配置数据。

访问：http://127.0.0.1:5000/#configure 。旧的 ?theme=classic 链接自动使用当前外观。

状态栏使用自动宽度与不压缩的状态项，避免旧的大屏 width 规则叠加左右 margin 后越界。手机菜单只显示顶部的小 Logo，隐藏桌面 Logo，四个页面纵向排列；当前页高亮，连接设备操作位于底部。菜单打开时背景不可聚焦，Tab 在可见控件内循环，选择页面或连接设备后关闭菜单。

node tests/refinements.test.cjs 验证转场耗时、320–1920px 状态栏范围、手机菜单、鼠标/触摸旋转与归位、占位文本移除及旧配色链接迁移。截图与耗时记录位于 test-results/refinements/。

点击反馈记录按钮触发时的屏幕轮廓，绘制到独立的手动 popover 顶层（旧浏览器降级为固定定位层）。使用 180ms 轻微按压回弹和 280ms 柔和轮廓高光，替代放射粒子；普通按钮保持中性灰白，主按钮带少许蓝色。打开原生 dialog 后，在下一绘制帧将反馈层提升到弹窗及其模糊背景之上；不拦截指针、不接管焦点，动画结束自动清理。按钮位移、内容重新渲染和面板模糊不会影响反馈。node tests/click-feedback.test.cjs 检查固定位置、原生弹窗顶层顺序、焦点、点击穿透、动画清理、分隔线及减少动画设置。

模型自由预览以每次拖动起点的姿态为基准，按相机的屏幕横纵轴计算旋转，不逐事件累计欧拉角。按视口大小调整灵敏度，主方向之外的 24px 小幅抖动忽略，刻意斜拖或弯曲拖动仍能组合旋转。28ms 时间常数平滑采样，松手后很快停稳，不附加惯性滑转；归位仍使用页面原有姿态动画。node tests/model-drag.test.cjs 验证反复旋转后方向一致、抖动抑制、反向及斜向拖动、原路拖回、停止和键盘/面板归位。
