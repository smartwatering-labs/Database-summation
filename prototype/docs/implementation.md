## 实现取舍

- 框架按文档使用 Flask + `templates/index.html`；前端使用原生 ES Modules，减少本期构建依赖。页面模块、通信服务、状态协调与样式分离。
- 四个用户页面用 hash 路由，在同一页面内跳转保留当前临时配置，刷新与关闭即清除。
- 不生成虚假整机 3D 模型；复用项目已有图片并保留后续媒体替换位置。
- 依据文档允许的图片替代方案，不增加 Three.js 空场景或伪装成实物的几何模型。
- 资料中土壤 ADC 与继电器电平有冲突，不据此输出湿度百分比或提供直接 GPIO 操作。
- 认证 secret 为文档公开开发值；不宣称已实现生产级加密。旧配置签名算法未给出，不伪造签名。
- 植物库与环境权重为明确标注的 seed 版本，后续可替换知识库文件与引擎而不改 UI。

以 [design.md](../design.md) 为基线，使用 Playwright Edge 截图与 `view_image` 检查。当前没有可操作的内置浏览器工具，因此使用本地 Playwright。

| 核对项 | 当前结果 |
| --- | --- |
| 页面内容 | 使用项目需求文案；不复用 X 网站营销内容 |
| 布局 | 桌面 208px 侧栏，主内容最大 1120px；手机 64px 顶栏与菜单 |
| 配色 | 白、黑、灰为主，状态使用少量语义色 |

| 图像 | 使用真实项目资料图并明确标注，不当成已完成的整机图 |
