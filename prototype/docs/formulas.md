# 当前配置计算公式

版本：2026.10.14-bound-config-and-device-summary。实现位于 `engine/rules.py` 的 `derive_parameters`、`formula_catalog`，配置边界位于 `engine/validation.py`。公式生成初始工程配置，设备按传感器直接读数、固定板级参数和运行保护条件执行浇水。

管理员入口：本机打开 http://admin.localhost:5000，输入管理员密钥后向下查看“计算公式”区域。也可访问带 `#formulas` 的管理端地址。对应只读接口为 `GET /api/admin/formulas`，需要管理域名和 Bearer 密钥。页面展示当前数据库系数与版本，不支持直接编辑公式代码。

## 符号与数据来源

`clamp(x,a,b)` 表示把 x 限制在闭区间 [a,b]。`round(x,n)` 使用 Python 的最近值舍入、恰好中点取偶数，n 为小数位数；省略 n 得到整数。括号与运算顺序以下表为准。

- B：数据库植物 `dailyMl`；b：植物 `threshold`。
- L：光照系数，初始遮阴 0.75、半日照 1、全日照 1.25。
- C：栽培系数，初始花盆 1、地栽 1.25；V：花盆容积，0.5–200 L。
- t、h：默认使用天气 API 温湿度；用户选择合格设备准备期报告后采用现场均值。海拔、预报降水和日照作为区域背景。
- Q：流量（mL/s）；W：可用储水量（L），0.5–1000。
- 植物值、L、C、季节间隔和自带泵流量以当前数据库版本为准；JSON 仅作首次初始化。

## 公式清单

| 项目 | 当前公式 | 范围与说明 |
| --- | --- | --- |
| 花盆体积系数 S | 花盆 `clamp((V/10)^0.55,0.4,2.5)`；地栽 `1` | 地栽不使用花盆体积修正 |
| 温度系数 T | `clamp(1+(t-22)*0.025,0.65,1.5)` | 使用所选输入温度 |
| 湿度系数 H | `clamp(1+(60-h)*0.004,0.8,1.25)` | 使用所选输入空气湿度 |
| 日需水量 D | `round(clamp(B*L*C*S*T*H,25,2500))` | mL/天 |
| 原始三项权重 a | `[soilWeight,tempWeight*T,airWeight*H]` | 植物基础权重来自数据库 |
| 归一化权重 | 前两项 `round(a[i]/sum(a),4)`；末项 `round(1-前两项之和,4)` | 保证最终和为 1 |
| 需求触发阈值 | `round(clamp(b-(L-1)*8+3,20,90),1)` | 固定无人值守偏移 +3 |
| 季节间隔 I | 数据库 `season[自动季节]` | 初始春秋 4 天、夏 2 天、冬 6 天；1.0 用于水量估算，2.0 同时下发 I×86400 秒的最短间隔 |
| 流量 Q | 自带泵读取知识库估值；电磁阀变体读取用户实测流量 | 当前自带泵估值 22，待样机实测；用户流量 1–200 mL/s |
| 估算单轮目标 G | `D*I` | mL，不强行突破次数上限 |
| 脉冲次数 N | `clamp(round(G/(Q*3000/1000)),1,12)` | 整数，1–12 次 |
| 单轮实际估算 R | `round(N*3000/1000*Q,1)` | mL，开泵固定 3000 ms |
| 水箱续航 | `round(W*1000/D,1)` | 天，不代表电池续航 |
| 保守轮次时长 | `N*(3000+25000) <= 360000` | 计入末次关泵间隔；生成最多 336 秒 |
| 水量不足提示 | `R < G*0.8` | 提示调整硬件或实测，不提高安全上限 |

自动季节使用当前 UTC 月份和已验证地点纬度：北半球 12–2 月冬、3–5 月春、6–8 月夏、9–11 月秋；南半球相反；纬度 0 按北半球处理。这是现有简化规则，未单独建模热带雨旱季。

## 本次调整与执行边界

原阈值公式使用 `无人值守 ? 3 : 0`；现在设备始终无人值守，统一 +3，移除表单选项。原流量对所有设备开放；现在自带泵固定读取数据库 `flowRateMlSec`（初始 22 mL/s，来自项目 0.022 L/s 资料），后端忽略客户端覆盖，仅电磁阀变体要求用户填写流量。真实泵型的固定值仍需硬件实测确认。

选择设备实测辅助时，合格准备期报告的温湿度进入本次计算，Q 继续来自知识库或用户输入。报告需与 2.0 目标及当前 revision 匹配，可信时间、十分钟准备期、至少 10 个有效样本、80% 有效率且完成不超过一小时；生成结果分别保留天气背景和设备报告来源。

导入配置仍校验：阈值 20–90，脉冲 1–12 次，开泵 500–5000 ms，关泵 5000–60000 ms，保守总时长不超过 360000 ms。新生成配置固定开泵 3000 ms、关泵 25000 ms。导入旧配置不会重新运行上述生成公式或自动改写历史参数。

新配置必须通过外部列表完成城市／直辖市选择及签名验证，并在生成时重新取得有效天气；任何失败均不使用静态环境生成。仅预览和生成配置不会启动水泵，发送按钮保留在配置预览原位，首次模式建议仍为 PREPARE。固件以土壤 ADC / 4095 归一化计算相对需求，雨量默认小于 1000 时抑制浇水；实际触发状态须实物联调，本页不把网页估算冒充固件实测结果。
