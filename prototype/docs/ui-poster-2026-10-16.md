# 本地 UI 与模型加载优化 · 2026-10-16

首页以整机、产品介绍以四层结构作为主体。放大两行标题，用浅灰绿纸面、深色文字和蓝色主要操作建立层级；说明入口改为开放式列表。桌面文字与模型左右对位，手机先给出标题和操作，再展示模型与说明。功能页沿用既有配置、蓝牙和设备操作。

## 加载与灯光

- 删除模板中的旧开发板占位图。冷加载和重复刷新都不请求该图片；慢加载、资源失败和 WebGL 不可用时提供文字状态。
- 暖主光、冷补光和窄幅轮廓光形成白色 ABS 的顶面、侧面及圆角明暗层次；真实地面投影保持柔和、靠近设备。
- GPU 环境贴图使用 128px 预滤波，保留柔光板与材料。长页面画布提高纵向采样分辨率并保留阴影边距。
- 模型数据与 Three.js / 加载器 / 灯光库并行下载；GPU 初始化各阶段之间交还浏览器帧，页面文字和操作先绘制。
- 模型及相关图形库使用离线生成的 gzip 副本。模型 11,908,252 → 2,934,588 字节；六项资源总计 14,386,386 → 3,468,775 字节，减少 75.9%。解压后逐字节一致，原 GLB、648 个 CAD 实体和四层结构保留。
- 静态文件使用 ETag 重验证。刷新模型只传输验证响应，配置和接口仍保持 no-store，没有增加用户数据持久化。

## 测量

本机 Edge 无头浏览器、1440 × 1000、软件 WebGL。限速为 10 Mbps、40ms 延迟；这些是可复现的实验条件，不代表每台真实设备的耗时。

| 场景 | 结果 |
| --- | --- |
| 限速冷加载，优化前模型就绪 | 约 12.90 秒 |
| 同一限速，优化后模型就绪 | 约 3.59 秒 |
| 独立验证：限速首次模型画面 | 约 3.64 秒 |
| 独立验证：限速重复打开 | 约 0.72 秒 |
| 本地首次模型画面 | 约 0.64 秒 |
| 本地重复打开 | 约 0.26–0.27 秒 |

首次本地加载仍记录到 61–67ms 的图形初始化长任务；重复加载的两轮测量均未记录超过 50ms 的长任务。并未宣称所有硬件上都完全无卡顿。

原始数据：`test-results/poster/performance/before.json`、`after.json`、`cache.json`。`profile-model.cjs` 为排查阶段注入标记，因此会禁用 HTTP 缓存；`measure-model-startup.cjs` 不拦截资源，用于真实缓存和首次画面测量。

## 设计技能与使用边界

已安装并读取 [MotionSites Prompt Capture](https://github.com/bingo33-gif/motionsites-promptcapture)、[Taste Skill](https://github.com/Leonxlnx/taste-skill) 及其现有项目改版指南、[Impeccable](https://github.com/pbakaus/impeccable)。MotionSites 的 [公开 3D 页面](https://motionsites.ai/3d-websites) 没有提供完整免费提示词，本次使用项目实际模型完成构图。

Taste 抽取方向为 Split Stage，seed 477849464。概念：实际白色整机与蓝色双层主板构成同一张产品海报的外观与内部视图；切页时结构连续变换，文字解释对应部件。沿用既有字体、蓝色操作和完整模型；没有增加无关照片、虚构素材或营销数字。

Impeccable 自动上下文引擎未能建立缓存目录，转为读取既有设计规范及技能指南。Taste 的自动浏览器检查两次遇到 CDP Page.enable 超时；静态 lint 指出了已有业务按钮/玻璃面板的阴影规则，本次保留这些功能区约定。验收采用项目 Playwright 测试和实际截图，没有将技能检查器记为通过。

人工视觉复核：主要改善是标题与模型的份量、开放列表的可读性、手机首屏操作和外壳明暗。局限是 CAD 原始外壳形状本身较简洁，实时面光与投影也不等同于离线路径追踪产品摄影。

改动已写入本地文件；没有执行提交、推送或部署。项目原有的文档文件及 stress-test 删除状态不属于本次修改。
