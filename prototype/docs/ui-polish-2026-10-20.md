# 展示页与工作区视觉微调 · 2026-10-20

四个路由统一使用纯白内容背景，侧栏和手机展开菜单以浅灰色 `#eef0f2` 区分。配置与设备页保留半透明面板；面板的中性灰叠在白底上与侧栏视觉一致。首页和产品介绍保留文字对模型的海报构图，缩小第二行灰色标题，使两行右边缘基本齐平；主次按钮和“连接模拟设备”的可见轮廓保持。桌面侧栏选中框恢复逐帧位移。磨砂 ABS 外壳使用略深的中性基色与更明确的落地阴影，保留原有灯位和粗糙度。

## 设计自检

自检参考 [Webby Awards 的网站评审维度](https://www.webbyawards.com/judging-criteria/)、[Awwwards 作品评分展示](https://www.awwwards.com/sites/self-aware) 和 [FWA 官方作品入口](https://www.thefwa.net/)。这些是质量参照，不代表本项目取得奖项或官方评分。

| 维度 | 实际检查与结果 |
| --- | --- |
| 排版 | 展示页标题在 1440px 为 60.48px、390px 为 36.08px；两行标题仍清楚，详情与模型各有独立阅读顺序。 |
| 留白 | 桌面左右对位；手机依次为标题、操作、模型、详情，模型周围有阴影余量。检查了 320、375、390、414、768、1440、1920px。 |
| 视觉层级 | 第一行深色标题更大；第二行灰色标题与其右边缘基本对齐。蓝色主要操作优先，描边次操作和独立的模拟设备入口次之。 |
| 色彩 | 四页内容和模型舞台共用纯白底色，浅灰侧栏建立固定分区；标题深浅对比与蓝色操作焦点保留。 |
| 动效 | 既有模型姿态与页面揭露继续工作；桌面导航指示框经逐帧测量可见位移；页面 3→4 切换期间底色一致。减少动态效果模式由既有交互回归覆盖。 |
| 微交互 | 主要、次要和模拟设备按钮具备可见轮廓及 hover/focus 状态；模型拖动、缩放、归位和详情窗口均通过回归。 |
| 响应式 | 320、375、390、414、768、1440、1920px 的四个页面无整页横向溢出；修正了 320px 配置表单内容被面板裁切的问题，移动菜单使用同一灰色导航面。 |
| 原创性 | 使用项目真实的 3D 整机与四层分解模型作为主视觉，文案与硬件结构直接对应。 |

磨砂外壳的 `roughness` 为 `.78`，`clearcoat` 为 `0`，`specularIntensity` 为 `.42`，并保留已有微粗糙度纹理。实拍级 ABS 表面还受原始 CAD 网格精度与浏览器实时渲染限制；最终视觉以本地浏览器截图为准。
