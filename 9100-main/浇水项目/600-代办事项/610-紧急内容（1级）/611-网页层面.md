# 网页层面

## 项目文件要求

- [ ] 明确网页信息架构：首页、产品介绍页面、个性化库编译页面、硬件情况查看页面。
- [ ] 首页不做完整实时数据面板，只显示蓝牙连接状态、兼容性提醒和必要摘要。
- [ ] 首页提醒用户 ESP32 Deep Sleep 时不能由网页远程唤醒，需要先按外置按钮唤醒。
- [ ] 首页提醒 Web Bluetooth 浏览器兼容限制，备用方案暂时不定。
- [ ] 实现或设计浏览器到 ESP32-C3 的蓝牙设备识别、连接、握手和失败提示。
- [ ] 硬件情况查看页面在未连接蓝牙前隐藏实时数据，并提示用户连接设备。
- [ ] 握手成功后展示设备 ID、固件版本、当前模式、植物配置、温度、湿度、土壤 ADC、雨量 ADC、浇水需求值。
- [ ] 增加近期数据查看入口，读取并展示一周以内历史采样数据。
- [ ] 个性化库编译页面改为类似 iOS 设置的分组面板结构。
- [ ] 个性化库编译页面覆盖植物、地点/国家、花盆或地栽、花盆大小、光照、无人值守、水源描述等输入。
- [ ] 将后端生成的配置包通过蓝牙编码、认证、必要时加密后下发 ESP32。
- [ ] 展示配置下发状态流：生成配置、前端发送、ESP32 校验、写入成功或失败、可选回报后端。
- [ ] 首页加入可自由转向的 Three.js 硬件 3D 模型；模型缺失时先用图片占位。
- [ ] 产品介绍页面先放置简短用途、工作原理说明和临时图片占位。
