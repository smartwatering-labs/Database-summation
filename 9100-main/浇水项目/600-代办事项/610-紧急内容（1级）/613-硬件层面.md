# 硬件层面

## 立即确认

- [ ] 当前继电器模块是高电平触发还是低电平触发。
- [ ] 水泵接在 NO 还是 NC，COM 接法是否和文档一致。
- [ ] 当前 PCB 上 GPIO3 到继电器输入的电路是否反相。
- [ ] 土壤传感器当前型号：电阻式还是电容式。
- [ ] 雨量传感器当前材质与腐蚀情况。
- [ ] 水泵额定电流、启动电流和实际流量。
- [ ] 舵机动作时电源是否跌落，是否影响 ESP32 或继电器。

## 与代码相关的硬件实测

| 实测项 | 目的 |
|---|---|
| 继电器输入 HIGH/LOW 时水泵状态 | 修正 `RELAY_ON/OFF`。 |
| 干土/湿土/水中 ADC | 修正土壤湿度映射。 |
| 干燥/有水雨量板 ADC | 修正雨量阈值。 |
| 水泵 3 秒出水量 | 校准单轮浇水量。 |
| deep sleep 电流 | 估算无人值守续航。 |
| 舵机擦拭期间电压 | 判断是否需要独立供电或滤波。 |

## 硬件结论写入位置

- PCB 与走线：写入 `121- 电路板情况`。
- 单片机与引脚：写入 `123.1单片机`。
- 传感器：写入 `123.2传感器.md`。
- 电源与电流：写入 `123.3电源.md`。
- 舵机、水泵、继电器：写入 `123.5运动器.md` 或新增执行器细分页。
