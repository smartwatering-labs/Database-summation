# 芯片程序层面

## 立即确认

- [ ] 确认继电器实际触发电平：当前代码为 `RELAY_ON LOW`、`RELAY_OFF HIGH`，旧背景为相反描述。
- [ ] 重新实测土壤 ADC 湿端/干端：当前代码 `15/5` 与旧背景 `1000/4095` 冲突。
- [ ] 确认土壤 ADC 有效范围 `3-300` 是否符合当前传感器。
- [ ] 确认雨量阈值 `1000` 在当前雨量板上是否可靠。
- [ ] 确认 GPIO10 给土壤传感器供电是否安全。

## 立即修正候选

- [ ] 将继电器电平封装为明确函数，避免直接依赖宏名造成误解。
- [ ] 在启动时强制水泵关闭，并用实测结果修正 `RELAY_ON/OFF`。
- [ ] 将 ADC 标定值从代码常量迁移到可配置项或专门标定文件。
- [ ] 统一配置字段命名，减少 `soilWeight` 与 `soil_weight` 的混用。
- [ ] 明确主固件和配置接收固件谁是当前主线版本。

## 风险说明

> [!danger] 水泵误触发风险
> 继电器电平冲突如果处理错误，可能导致上电时水泵误开或无法关泵。这个问题优先级高于网页展示和算法优化。
