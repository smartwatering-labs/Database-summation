# 网页改动

## 项目文件同步

- 将网页定位更新为普通用户主要入口，首页提供硬件展示和三个快速跳转。
- 新增三个子页面要求：产品介绍页面、个性化库编译页面、硬件情况查看页面。
- 将蓝牙连接提升为网页主链路，要求支持设备识别、握手、实时数据同步、历史数据读取和配置下发。
- 个性化库编译页面要求采用类似 iOS 设置的分组面板结构，收集植物、地点、栽培方式、花盆大小、光照、无人值守、水源等信息。
- 后端职责扩展为资料库匹配、第三方环境 API 调用、参数解算、配置包生成与存储。
- 首页 Three.js 硬件 3D 模型暂未具备时，可先用图片占位。
