# 术语使用规范

## 运行模式

| 术语        | 含义       | 备注                                    |
| --------- | -------- | ------------------------------------- |
| `DISPLAY` | 展示/调试模式  | 冷启动默认进入；周期性采样并刷新 OLED 与可供蓝牙读取的状态。    |
| `PREPARE` | 准备/校准模式  | 正式长期运行前的准备窗口；用于采集基准数据。                |
| `LONGRUN` | 长期实地运行模式 | deep sleep 定时唤醒，采样、决策、必要时浇水。 |

## 数据与算法

| 术语 | 含义 |
|---|---|
| `wateringDemand` / `curD` | 当前浇水需求值，范围 0-100。代码中主要变量名为 `curD`。 |
| `soilDryness` | 土壤干燥度，由土壤 ADC 读数映射得到。 |
| `tempStress` | 温度胁迫值，温度超过基准后增加。 |
| `airDryness` | 空气干燥度，通常由 `100 - humidity` 得到。 |
| `threshold` | 浇水触发阈值，需求值达到或超过时才可能启动浇水。 |
| 雨量硬否决 | 检测到下雨时直接将需求值清零，不执行自动浇水。 |
| 中位数滤波 | ADC 读取 5 次排序，取中间值作为有效值。 |

## 执行器与动作

| 术语 | 含义 |
|---|---|
| 脉冲浇水 | 水泵多次短时间开启，中间留间隔，避免一次性浇水过量。 |
| `pulseCount` | 一轮浇水中的开泵次数，默认 9。 |
| `pulseOnMs` | 单次开泵时长，默认 3000 ms。 |
| `pulseOffMs` | 两次开泵之间的等待时长，默认 25000 ms。 |
| 擦拭 | 舵机带动刷子清理雨量传感器，代码动作为 150 度与 60 度往复。 |

## 配置与通信

| 术语 | 含义 |
|---|---|
| NVS | ESP32 非易失性键值存储，代码中用 `Preferences` 保存配置。 |
| SPIFFS | ESP32 文件系统，代码中用于保存日志、历史采样记录或本地配置文件。 |
| `SWS-HS` | 配置接收固件中的握手协议标识。 |
| nonce | 握手接口生成的一次性随机字符串，用于认证。 |
| auth | `sha256(nonce + SECRET_KEY)` 得到的认证字段。 |
| revision | 设备本地配置版本号。主固件要求新配置的 `revision` 大于当前配置；它不代表后端保存配置历史版本。 |
