# 调用库

## 单片机主固件

| 库 | 用途 |
|---|---|
| ESP32 BLE 相关库 | 与用户设备通过蓝牙发现、握手、传输配置和同步采样数据。 |
| `Wire.h` | I2C 通信，OLED 使用。 |
| `U8g2lib.h` | OLED 显示。 |
| `DHT.h` | 读取 DHT 温湿度传感器。 |
| `ESP32Servo.h` | 控制 9g 舵机擦拭雨量传感器。 |
| `SPIFFS.h` | 保存日志、历史采样记录或本地配置文件。 |
| `Preferences.h` | 使用 NVS 保存配置参数。 |
| `ArduinoJson.h` | 解析和生成配置 JSON、接口返回 JSON。 |
| `algorithm` | 对 ADC 采样数组排序，取中位数。 |
| `esp_sleep.h` | 进入 deep sleep，设置定时唤醒。 |
| `esp_task_wdt.h` | 看门狗，防止主循环卡死。 |
| `esp_crc.h` | 计算配置 CRC。 |

## 配置接收固件

| 库 | 用途 |
|---|---|
| `mbedtls/sha256.h` | 计算 `sha256(nonce + SECRET_KEY)` 用于配置上传认证。 |
| `esp_system.h` | 获取随机数等系统能力。 |

## 网页平台后端

| 模块 | 用途 |
|---|---|
| `Flask` | 提供 Web 应用和 REST API。 |
| `sqlite3` | 保存权重库、系统维护日志、外部 API 降级记录等后端运行数据。 |
| `json` | 读取知识库与返回 JSON。 |
| `urllib.request` | 调用 Open-Meteo 或其他环境 API，失败时降级到静态地点数据。 |
| Open-Meteo API | 可作为无 key 的地理天气资料来源，用于海拔、降水、湿度、日照等环境标签补充。 |
| `engine.rules` | 参数推导。 |
| `engine.code_generator` | 旧方案或后续扩展中的固件代码生成能力；第一阶段主线不依赖代码版本管理。 |

## 重要依赖边界

- ESP32 端需要控制内存占用，JSON 文档大小不能无限扩大。
- SPIFFS 和 NVS 写入次数有限，配置与日志写入应避免高频无意义写入。
- DHT、舵机、OLED、BLE 同时运行时要注意供电稳定性。
